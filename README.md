# AI Learning Roadmap Generator

An AI-powered application that generates personalized
learning roadmaps based on user requirements.

## Technologies Used

- Python
- Streamlit
- Groq API
- Llama 3.3 70B

## Features

- Select a learning field
- Choose beginner, intermediate or advanced level
- Select learning duration
- Set daily study hours
- Generate personalized learning roadmaps
- Download roadmaps in Markdown format

## Installation

1. Clone the repository.

2. Install dependencies:

pip install -r requirements.txt

3. Set your Groq API key:

GROQ_API_KEY=your_api_key

4. Run the application:

streamlit run app.py

## Deployment

Deploy using Streamlit Community Cloud.
